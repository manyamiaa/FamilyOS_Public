# Weekly digest: automation registry

The Saturday digest runs each enabled entry in this order and gives each one a section.
**Default for any new automation:** add a row here rather than scheduling it separately.

| Order | Section | Skill | What it does | Enabled |
|---|---|---|---|---|
| 1 | Birthdays | `upcoming-birthdays` (+ `gift-ideas`) | Birthdays in the next 28 days: gift status, suggested ideas for anyone without one, ⚠️ for ≤14 days with nothing chosen | yes |
| 2 | Meal plan | `meal-planning` | Draft lunch + dinner plan for next Mon–Fri plus a grocery list (status: draft) | yes |
| 3 | Baby's activities | `baby-activities` | 5 age-targeted activities for the week, plus a milestone note when he crosses a CDC checkpoint | yes |
| 4 | Baby's journal | `baby-memories` | Entries added this week; a gentle nudge if nothing added in 14+ days | yes |

Schedule: **Saturday morning** (one scheduled task runs the `weekly-digest` skill).
