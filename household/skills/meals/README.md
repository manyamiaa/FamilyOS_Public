# Meals

Two skills share this folder's data:

| Skill | Does |
|---|---|
| `add-recipe/` | Add recipes (extraction, tagging), log cooking, ratings, tweaks |
| `meal-planning/` | Weekly lunch + dinner plan, grocery list, recipe lookups, digest section |

| Shared data | |
|---|---|
| `data/preferences.md` | Hard restrictions (no pork), plan scope, meal composition, grocery sections |
| `data/staples.md` | Always-in-the-house items, kept off grocery lists |
| `data/recipes/<slug>.md` | One file per recipe (`templates/recipe.md`) |
| `data/meal-plans/YYYY-Www.md` / `-grocery.md` | Weekly plans and grocery lists (`templates/meal-plan.md`, `templates/grocery-list.md`) |
